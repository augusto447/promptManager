# 🤖 Prompt Manager

O **Prompt Manager** é uma aplicação web desenvolvida durante o **NLW da Rocketseat**, criada para facilitar a organização e gestão de prompts utilizados com ferramentas de Inteligência Artificial.

O projeto foi desenvolvido com foco em uma interface simples, funcional e intuitiva, permitindo ao utilizador organizar e trabalhar com diferentes prompts de forma prática.

## 🚀 Funcionalidades

* 📝 Criação e gestão de prompts
* 🔎 Organização e consulta de prompts
* 📋 Visualização dos prompts
* 🎨 Interface moderna e responsiva
* ⚡ Interações desenvolvidas com JavaScript
* 🤖 Integração com recursos de IA

## 🛠️ Tecnologias

* **HTML5** — Estrutura da aplicação
* **CSS3** — Estilização e responsividade
* **JavaScript** — Lógica e interatividade
* **Figma** — Design e prototipação da interface
* **MCP (Model Context Protocol)** — Integração com recursos e ferramentas de IA

## 🎨 Design

A interface foi inicialmente planejada e prototipada no **Figma**, permitindo estruturar a experiência do utilizador antes da implementação.

O design foi posteriormente transformado em uma aplicação web utilizando HTML, CSS e JavaScript.

## ⚙️ Como executar

### 1. Clonar o repositório

```bash
git clone https://github.com/augusto447/promptManager.git
```

### 2. Entrar na pasta

```bash
cd prompt-manager
```

### 3. Executar

Por ser uma aplicação frontend baseada em HTML, CSS e JavaScript, pode ser executada diretamente no navegador ou através de uma extensão como **Live Server** no VS Code.
